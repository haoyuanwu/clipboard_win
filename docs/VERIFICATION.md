# Windows 验证记录

验证日期：2026-10-23（Asia/Hong_Kong）。

## 1.3.2

- 固定对照原版提交 63416c3ab0518c3cf2a07ed5c17a411be117b8d6。
- `flutter analyze lib test` 无问题，26 项 Flutter 测试通过，包括部分文件失效复制、清理保护/复查/写入失败回滚、虚拟文件暂存与弹窗按搜索和记事本结果编号复制。
- 独立 C++ 原生测试通过：混合 HGLOBAL/IStream 虚拟文件读入、第二项失败时整组取消、路径穿越文件名拒绝、流长度不符取消，失败后无残留暂存目录。
- 已打包的隔离实例中验证主窗口、托盘、中转站及 Windows 右侧按钮；最小化、最大化（本机可用宽 1920）、还原、隐藏正常。
- 主窗口隐藏时，两组真实全局 Ctrl+Alt+C / Ctrl+Alt+V 均能显示、隐藏目标窗口。
- 可选 macOS 模式主标题升级为 52，首卡 (16,110)；设置 420×560；新版卡片分隔线和媒体最高 176。深浅色布局及 320×360 中转最小尺寸由界面测试覆盖。
- 发现 Release 裁剪的 Cupertino 字体丢失省略号图标，发布构建已使用 --no-tree-shake-icons；脚本比对完整源字体，阻止再次发布缺失字体的包。
- 收纳入口采用 Windows 屏幕边缘触发；文件/虚拟文件落地逻辑有原生测试，任意第三方应用的实际 OLE 投放仍需更多人工覆盖。

- 实际 Windows 剪贴板：Unicode 文字、重复合并、RTF、文件列表和 DIB 图片捕获通过。
- 最终运行包：主窗口、托盘弹窗与置顶中转站能够显示；托盘单击复制实际写回系统剪贴板，复制次数只增加一次。

- 多文件以整组文件夹拖回的去重规则已加入回归测试。
- macOS 模式视觉对齐检查：主窗口 440×640、托盘 390×520、中转站 350×520；整合标题栏与红黄绿按钮；首张卡片 (16,104)、宽 408；设置 390×440、详情 420×420、退出确认宽 310；420 宽的浅/深色与中转站 320×360 最小尺寸无溢出。

- v1.2.1 Windows 模式：右侧 3 个 46×32 按钮，默认启用；新设置保存后主窗口和中转站即时切换；旧存档没有标题栏偏好时默认 Windows。实际最小化、最大化、还原、隐藏窗口通过，最大化宽度达到当前显示器可用宽 1920，macOS 模式仍为 460。真实菜单的双向切换、深色主题及中转站同步已核对。
- 最新磨砂版本：托盘、中转、设置、详情、关于、退出面板共用半透明模糊表面，模糊 sigma 28。桌面窗口请求 Acrylic，不再回退为清晰透明；当前系统 EnableTransparency=0，实际验证为较实的系统材质回退，未在系统透明开启状态下验证桌面模糊。
- Windows 11 托盘首次可见偏好：实际演示程序的 IsPromoted=1、SuperClipboardDefaultVisible=1 已确认；后续运行保留手动显示选择。此兼容处理受 Windows 版本和任务栏策略影响。
- 发现用户已运行旧版后，最终检查改为专用 --preview-instance（必须同时使用独立目录、--no-capture、--no-startup），窗口脚本按进程 ID 定位，避免命中用户实例。
- 本轮界面预览使用 `--no-capture --no-startup` 与独立示例存档，不采集个人剪贴板，也不修改开机启动。
- 检查截图：`screenshots/windows-main.png`、`screenshots/windows-popover.png`、`screenshots/windows-transfer.png`、`screenshots/transfer-frosted.png`；主题布局截图见 `main-light.png`、`main-dark.png` 和 `settings-dark.png`。
