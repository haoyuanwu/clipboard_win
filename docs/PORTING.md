# Windows 复刻说明

源工程：haoyuanwu/SuperClipboard，参考提交 0739f49d1494a69b46a041258efe0204fa5d13d2。

## 结构与视觉

保留约 440 逻辑像素宽的单列主窗口、16 像素卡片圆角、16 像素卡片内边距、12 像素卡片间距，沿用原项目主题色和来源应用着色规则。
直接使用原项目的品牌图标。Windows 使用 Segoe UI，中文回退 Microsoft YaHei UI，图标使用 Cupertino Icons。

默认采用 Windows 标题栏（高 32，右侧按钮各宽 46），下方为高 44 的搜索和功能工具栏。主窗口默认 440×640，首张卡片起点为 (16,134)。设置中的“标题栏样式”可切换到 macOS：整合式标题栏与左侧红黄绿按钮；托盘弹窗 390×520；中转站 350×520；设置/关于 390×440；详情 420×420。macOS 模式标题栏 46、分类栏 42，首张卡片的左上角为 (16,104)，宽 408。边框作为覆盖层绘制，避免挤占卡片内边距。具体对照见 `VISUAL_ALIGNMENT.md`。

主窗口、托盘弹窗和中转站分别使用 Flutter 引擎；主引擎串行处理数据修改，辅助窗口通过 Windows 平台通道共享快照，避免并发写存档。
辅助引擎启动时会等待 Windows 通信接口注册。

## 对应实现

| 原版交互或规则 | Windows 实现 |
| --- | --- |
| 自动记录文字、图片、文件和视频 | Windows 剪贴板监听；Unicode、HTML、RTF、PNG/DIB、CF_HDROP |
| 来源应用和卡片颜色 | 读取剪贴板来源进程，提取图标与代表色 |
| 重复内容合并计数 | 文字、图片内容与文件组指纹；合并 Windows 短时间重复通知 |
| 打开期间卡片不跳动 | ListSession 保存本次窗口顺序，新记录追加；重开或切换排序时刷新 |
| 时间排序与次数排序 | 首次记录时间、复制次数、置顶优先，共享并持久化 |
| 主页面点击看详情 | Flutter 详情对话框，复制成功短暂停留后关闭 |
| 菜单栏弹窗直接复制 | 系统托盘弹窗直接复制，并显示复制反馈 |
| 记事本独立副本 | 独立索引与附件目录，保存完成后脱离源文件 |
| 更改记事本位置 | 复制并校验可读取路径，提交新索引；失败回退，成功保留旧备份 |
| 悬浮中转 | 独立置顶窗口，OLE 拖放，独立副本与去重 |
| 中转关闭后清空 | 1–1440 分钟，重新打开取消；重启后恢复截止时间 |
| 多文件作为一组拖出 | 作为包含全部文件的应用副本文件夹拖出 |
| 视频封面与播放 | Windows Shell 缩略图与 media_kit 播放器 |
| 浅色、深色与跟随系统 | Flutter 主题与 Windows 系统亮度 |
| 开机启动 | 当前用户 Run 项；首次配置后读取已有注册状态 |
| 托盘图标默认可见 | Windows 11 按当前可执行文件路径设置本图标的首次可见偏好；不修改其他图标或整个任务栏，后续手动选择不覆盖；旧版 Windows 或任务栏策略可能不支持 |
| 主窗口关闭后后台运行 | 隐藏窗口并保留系统托盘；退出停止监听 |

## 平台差异与边界

- 系统托盘与资源管理器替代 macOS 菜单栏和访达。辅助窗口使用逐像素透明、淡色渐变、圆角和原生阴影，并请求 Windows Acrylic 背景模糊。统一使用半透明磨砂表面，移除清晰透出桌面的回退；系统关闭“透明效果”时由 Windows 提供较实的材质，高对比度模式使用实色。不会自动修改系统设置。
- 未获得原版截图，因此视觉依据为原项目源码中的尺寸、布局、颜色与交互。Windows 字体栅格化和原生背景材质与 macOS 有差异，尚不能确认截图级像素一致。
- 原始 HTML/RTF 数据保留用于再次复制。HTML 预览禁用远程媒体；RTF 预览支持常见字号、颜色、粗体、斜体、下划线、删除线和换行，复杂 RTF 排版、嵌入对象和完整字体表不会完全重现。
- 原始历史文件记录不复制源文件，因此源文件移动或删除后可能不可用。加入记事本或中转并保存成功的副本继续可用。
- 视频封面由 Windows Shell 能力决定；没有封面时显示占位。播放器支持的格式取决于随包提供的 libmpv。
- 文件夹内的链接会拒绝归档并保留源内容，不跟随链接递归复制。
- 开机启动遵守 Run 项状态，任务管理器的额外“启动应用”禁用规则仍由 Windows 管理。
- OLE 拖动到任意第三方软件的接受行为需由目标软件决定，跨应用拖动仍需人工覆盖更多目标。
