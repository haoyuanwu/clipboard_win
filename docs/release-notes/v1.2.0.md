# SuperClipboard Windows v1.2.0

SuperClipboard 的首个 Windows 发布版，以 Flutter 实现，界面和主要交互参考同账号的 macOS 原项目。

## 功能

- 自动保存文字、富文本、图片、文件和视频记录，支持搜索、分类、置顶和重复计数。
- 托盘弹窗快速复制，主窗口查看详情，浅色、深色与跟随系统。
- 记事本独立保存副本，支持更换保存目录。
- 悬浮中转站支持拖入、拖出，以及关闭后定时清理。
- 半透明磨砂界面；Windows 11 首次运行尝试直接显示托盘图标。

## 下载与安装

- `SuperClipboard-1.2.0-windows-x64-setup.exe`：中文安装向导，默认安装到当前用户目录，无需管理员权限，提供卸载入口。
- `SuperClipboard-Windows-x64-v1.2.0.zip`：免安装版，解压完整文件夹后运行 `SuperClipboard.exe`。
- `SHA256SUMS.txt`：两个下载文件的 SHA-256 校验值。

升级前请从托盘退出旧版。默认历史目录为 `%APPDATA%\SuperClipboard`，卸载程序不会主动删除该目录。

## 验证与说明

已通过 17 项自动测试、静态检查和 Windows 11 x64 Release 构建；已验证实际主窗口、托盘弹窗、中转站及窗口按钮。安装程序已通过编译，未在当前日常使用环境中执行安装/卸载。

当前构建未进行商业代码签名。Windows 关闭系统透明效果时，桌面毛玻璃会显示为较实的材质。复杂富文本、跨软件拖放和不同视频格式仍受各自组件与目标软件支持范围影响。

原 macOS 项目：[haoyuanwu/SuperClipboard](https://github.com/haoyuanwu/SuperClipboard)。
