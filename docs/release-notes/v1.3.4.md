# 口袋Cube Windows v1.3.4

- 应用正式更名为“口袋Cube”，同步主窗口、托盘、快捷历史、关于与退出提示，以及 Windows 文件属性中的产品名称。
- 安装程序、开始菜单及桌面快捷方式使用新名称，免安装程序与发布附件使用 PocketCube 文件名。
- 沿用旧版数据目录和安装升级标识，保留剪贴板历史、记事本、中转站与已有设置；升级安装时清理旧名称的快捷方式与程序入口。
- 继续支持设置 → 通用与外观 → 开机启动，登录 Windows 后在托盘后台运行。

下载 PocketCube-1.3.4-windows-x64-setup.exe 安装，或完整解压 PocketCube-Windows-x64-v1.3.4.zip 后运行 PocketCube.exe。升级前从托盘退出旧版，保留同目录的 DLL 和 data 文件夹。SHA256SUMS.txt 提供附件校验。
