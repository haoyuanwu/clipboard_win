# SuperClipboard Windows v1.3.2

以原版 SuperClipboard 1.3.2 为基线，补齐新功能和新版界面，同时保留 Windows 原生操作习惯。

- 全局 Ctrl+Alt+C / Ctrl+Alt+V 打开快捷历史与悬浮中转；可录制、停用和恢复默认，冲突时保留旧组合。
- 托盘弹窗 Ctrl+1–9 按当前搜索或记事本结果复制；所有列表均可拖出，拖动不改变复制次数和当前顺序。
- 中转文件组可展开并逐项复制、拖出、定位。拖动文件到屏幕右上角显示收纳入口，松手后保存副本并打开中转站。
- 支持常见虚拟文件数据源，完整读入后归档，失败取消整组。
- 定期检查失效内容；部分失效的文件组可使用剩余文件。快捷清理会确认并复查，保护置顶、记事本和部分可用条目，写入失败恢复记录。
- 对齐新版主标题、工具菜单、托盘整行搜索、卡片分隔、媒体高度及设置表单，换用新版盒子取卡 Logo 和黑白托盘图标。
- Windows 默认右侧最小化、最大化/还原、关闭；设置可切换 macOS 样式。辅助窗口和面板保留半透明磨砂，中转站失焦时更通透。

下载 setup.exe 安装，或完整解压 zip 运行；SHA256SUMS.txt 提供校验。升级前从托盘退出旧版，个人数据目录与已有设置保留。

Windows 采用 Acrylic、资源管理器定位和 CF_HDROP 多文件拖放。原生字体、系统材质、边缘触发收纳方式与 macOS 有差异；完整说明见仓库 docs/PORTING.md。当前发布包未做商业代码签名。
