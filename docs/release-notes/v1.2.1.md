# SuperClipboard Windows v1.2.1

本次增加 Windows 与 macOS 两种标题栏样式，默认采用 Windows 样式。

- 右侧依次排列最小化、最大化/还原和关闭按钮，关闭按钮悬停为红色。
- 搜索和常用功能放在独立工具栏，Windows 模式支持完整最大化、还原、标题栏双击和右键系统菜单。
- 在 **设置 → 外观 → 标题栏样式** 中可即时切换到 macOS，恢复左侧红黄绿按钮；选择会保存，主窗口和中转站同步更新。
- 升级时没有样式偏好的旧存档默认使用 Windows；剪贴板记录和记事本继续保留。
- 设置和关于面板的关闭按钮也随样式调整。

已通过静态检查、20 项自动测试和 Windows Release 构建；在隔离演示实例中验证两种按钮布局、窗口操作、设置保存和深色布局。Windows 按钮为自绘，目前没有原生最大化按钮悬停的 Snap Layouts 面板。

## 下载与升级

- `SuperClipboard-1.2.1-windows-x64-setup.exe`：当前用户中文安装程序。
- `SuperClipboard-Windows-x64-v1.2.1.zip`：免安装运行包。
- `SHA256SUMS.txt`：两个下载文件的校验值。

升级前请从托盘退出旧版。默认数据保存在 `%APPDATA%\SuperClipboard`，卸载不会主动删除个人历史。当前安装包未做商业代码签名；系统关闭透明效果时毛玻璃使用较实的材质回退。
