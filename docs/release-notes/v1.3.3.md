# SuperClipboard Windows v1.3.3

- 修复桌面文件、文件夹拖动时入口不出现的问题；主页面关闭后仍可在当前屏幕左上角唤出收纳入口，普通拖选与文字拖动不会误弹窗。
- 修复松手时入口过早隐藏造成文件没有收纳的问题。投放后立即打开中转站，文件夹支持“作为文件组”“保留文件夹”或取消，并可记住选择。
- 文件组使用专用图标，展开第一层内容，保留子文件夹、空文件夹和单成员组，重复拖回中转副本不会产生重复记录。
- 快捷键冲突提示明确显示功能名与被占用的组合键，点击直达快捷键设置；修改成功或停用后清除对应提示。
- 优化卡片来源图标、文件组预览，以及悬浮中转和记事本的存储设置布局。

下载 setup.exe 安装，或完整解压 zip 后运行 SuperClipboard.exe。升级前从托盘退出旧版，保留个人历史、记事本和设置。校验文件为 SHA256SUMS.txt。

如果此前勾选了“下次不再询问”，可在设置 → 悬浮中转 → 拖入文件夹中改回“每次询问”。
