# 1.3.2 功能与界面对齐

固定参考：[macOS 原版 1.3.2](https://github.com/haoyuanwu/SuperClipboard/tree/63416c3ab0518c3cf2a07ed5c17a411be117b8d6)。Windows 保留原版主窗口、托盘弹窗、中转站三个独立场景。

| 原版行为 | Windows 对应 |
| --- | --- |
| 文字、HTML/RTF、图片、文件和视频历史 | Windows 剪贴板监听与媒体预览；历史文件继续引用原路径 |
| 去重、置顶、时间/次数排序、稳定列表 | 已实现；拖动不更新复制次数，打开期间复制不重排 |
| 独立记事本及迁移 | 独立副本、去重、独立索引、迁移失败回退 |
| 所有列表拖出 | 主窗口、托盘、记事本、中转均支持；Windows 原生多文件选择导出 |
| 文件组展开和逐项操作 | 数量徽标、图片封面、展开/收起、单文件复制/拖出/定位 |
| 角落收纳 | Windows 适配为拖向当前屏幕右上角触发，只接受文件，保存后打开中转 |
| 其他软件提供的文件数据 | Unicode 文件描述符、IStream/HGLOBAL 混合源；先完整暂存再归档 |
| 原内容失效兜底 | 每 15 秒及窗口打开时检查，部分文件缺失可继续使用剩余部分 |
| 失效记录清理 | 确认后复查；保护置顶、部分可用和记事本；提交失败回滚 |
| 全局弹窗/中转快捷键 | Ctrl+Alt+C/V；录制、停用、恢复默认、冲突回退 |
| 弹窗数字复制 | Ctrl+1–9，按当前搜索/记事本结果编号，越界不操作 |
| 新版标题、卡片、整行搜索 | 主标题/副标题、合并工具菜单、元信息分隔线、媒体最高 176 |
| 新版设置 | 外观选项卡、快捷键录制、可展开维护、检查反馈、清空确认 |
| 盒子取卡 Logo / 黑白菜单图标 | 复用原素材；托盘图标根据 Windows 任务栏明暗切换 |
| 玻璃与原生窗口 | Windows Acrylic + Flutter 模糊；失焦中转降低蒙层，Windows 右侧按钮默认，可选 macOS 左侧按钮 |

无原版运行截图，当前依据源码参数对齐；字体、系统材质及 Windows 原生能力差异见 [复刻说明](PORTING.md)。不声称像素完全一致。虚拟文件的旧式 ANSI、嵌套目录、IStorage 以及任意第三方应用的全部拖放行为仍有平台限制。
